Guia de Permissões
Módulo de Usuários
  • users_view: Visualizar usuários
  • users_create: Criar novos usuários
  • users_edit: Editar usuários existentes
  • users_delete: Excluir usuários
Módulo de Certificados
  • certificates_view: Visualizar certificados
  • certificates_create: Criar certificados
  • certificates_edit: Editar certificados
  • certificates_delete: Excluir certificados
  • certificates_download: Download de arquivos
Módulo de Contas
  • accounts_view: Visualizar contas cloud
  • accounts_create: Criar contas
  • accounts_edit: Editar contas
  • accounts_delete: Excluir contas
Módulo de Recursos
  • resources_view: Visualizar recursos
  • resources_create: Criar recursos
  • resources_edit: Editar recursos
  • resources_delete: Excluir recursos
Módulo de Permissões
  • permissions_view: Visualizar permissões
  • permissions_create: Criar permissões
  • permissions_edit: Editar permissões
  • permissions_delete: Excluir permissões
  • permissions_bulk: Atribuição em massa
Importante: Permissões de administração devem ser concedidas apenas a usuários confiáveis.
Dicas de Uso
Boas Práticas
  • Selecione usuários com cuidado antes de aplicar
  • Use permissões específicas em vez de conceder tudo
  • Teste com poucos usuários primeiro
  • Documente mudanças importantes
  • Revise permissões periodicamente
Cuidados
  • Evite conceder permissões desnecessárias
  • Não remova permissões críticas sem verificar
  • Cuidado com usuários inativos
  • Monitore atividades após mudanças
  • Mantenha backup das configurações
